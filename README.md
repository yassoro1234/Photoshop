# Photo Studio

محرر صور بأسلوب Photoshop: مساحة عمل داكنة، أدوات حقيقية، طبقات ومجموعات وأقنعة، تعديلات وفلاتر مع معاينة فورية، ومشاريع متعددة. يعمل في المتصفح، ويُبنى كتطبيق Android عبر GitHub Actions.

> هذا التطبيق مستقل ولا يتبع Adobe ولا يستخدم شعاراتها.

## المزايا

- **الواجهة:** شريط قوائم (File وEdit وImage وLayer وSelect وFilter وView وWindow وHelp)، شريط أدوات يسار، شريط خيارات يتغير حسب الأداة، ولوحة طبقات قابلة لتغيير العرض، وشريط حالة.
- **الأدوات:** Move، Marquee، Lasso، Quick Selection، Crop، Brush، Eraser، Clone Stamp، Gradient، Paint Bucket، Text، Pen، Eyedropper، Hand، Zoom.
- **الطبقات:** إنشاء وحذف ونسخ وإعادة تسمية، إظهار وإخفاء وقفل، شفافية، أوضاع مزج، مجموعات قابلة للطي، أقنعة طبقات، دمج وتسطيح، طبقات نص، واستيراد الصور كطبقات.
- **التعديلات:** السطوع والتباين، التعريض، الصبغة والتشبع، درجة الحرارة، توازن الألوان، المستويات، المنحنيات، طمس غاوسي، تحديد الحواف، ضوضاء، تدرج الرمادي، عكس الألوان، تظليل الحواف. كلها بمعاينة فورية.
- **الملفات:** مستند جديد بمقاس مخصص، فتح وحفظ مشروع (`.psproj.json`)، تصدير PNG وJPG وWebP مع خلفية شفافة للـ PNG و WebP، وتبويبات لعدة مشاريع مفتوحة.
- **الاستعمال:** اختصارات لوحة المفاتيح، قوائم سياقية بالنقر المطول أو الزر الأيمن، لمس بإصبعين للتكبير على الهاتف.

## التشغيل محلياً

افتح `www/index.html` في المتصفح مباشرة، أو شغّل أي خادم ثابت داخل مجلد `www/`.

## بناء APK للأندرويد

البناء يتم تلقائياً في GitHub Actions عند كل دفعة (push) إلى `main`، ويُنشر الناتج في **Releases** باسم `build-<رقم>`، فتحمّل ملف `.apk` مباشرة من صفحة الإصدارات.

### 1. إعداد مفتاح التوقيع (مرة واحدة)
لنشر التطبيق على Google Play يلزم توقيع الإصدار بمفتاح ثابت. أضف هذه الأسرار في
**Settings → Secrets and variables → Actions → New repository secret**:

| الاسم | القيمة |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | محتوى ملف `keystore.b64` كاملاً |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة مرور المفتاح |
| `ANDROID_KEY_ALIAS` | `photostudio` |
| `ANDROID_KEY_PASSWORD` | كلمة مرور المفتاح (نفسها) |

> **مهم:** احتفظ بنسخة من ملف `release.keystore` وكلمات المرور في مكان آمن. فقدانها يعني أنك لن تستطيع تحديث التطبيق على Google Play لاحقاً.

بدون هذه الأسرار يُبنى APK تجريبياً (debug) يعمل للتجربة المباشرة فقط، ولا يُقبل على Google Play.

### 2. النشر على Google Play
1. أنشئ حساب مطور في Google Play Console (رسوم لمرة واحدة).
2. أنشئ تطبيقاً جديداً، واختر اسم الحزمة `com.yasser.photostudio`.
3. ارفع ملف `.aab` (من صفحة الإصدار) إلى مسار **Internal testing** أولاً.
4. أكمل قائمة المتجر: الوصف، لقطات الشاشة، أيقونة 512×512 (في `resources/icon-512.png`)، سياسة الخصوصية، وتصنيف المحتوى.

## الهيكل

```
www/                 واجهة التطبيق (HTML/CSS/JS بدون مكتبات)
  js/state.js        الحالة والمساعدات
  js/doc.js          نموذج المستند، العرض، التراجع، الطبقات، التحديد
  js/view.js         التكبير والتحريك
  js/tools.js        الأدوات ومعالجة اللمس والفأرة
  js/adjust.js       التعديلات والفلاتر والمنحنيات
  js/image.js        تحويل الصور، القص، النص
  js/io.js           الاستيراد والتصدير والمشاريع والتبويبات
  js/ui.js           القوائم، الأدوات، الخيارات، لوحة الطبقات، الاختصارات
  css/app.css        المظهر والتخطيط والوضع الفاتح
resources/           أيقونة التطبيق
scripts/signing.gradle  إعداد التوقيع في Gradle
capacitor.config.json   إعداد Capacitor (اسم التطبيق، المجلد، اسم الحزمة)
.github/workflows/android.yml  بناء APK/AAB ونشر الإصدار
```
